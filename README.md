# LAB 5 - Adaptive E-Commerce Item Detail Screen

## Project
Sneaker Store Flutter App

## Features
- Product feed screen
- Product detail screen
- Stack cover image
- Bookmark button
- Rating and price row
- Category badges with Wrap
- Quantity counter
- Sticky bottom action bar
- Add to Cart button with Expanded
- StatefulWidget and setState
- Responsive layout with no RenderFlex overflow

## Run
flutter pub get
flutter run
